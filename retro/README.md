# Письмо · Ретро — версия для Outlook

Редактор: https://coopersino.github.io/mail-studio-light/retro/

Редактируются тема, заголовок, основной текст, приглашение добавить темы, текст о длительности, подпись и ссылка кнопки. Черновик сохраняется в localStorage этого браузера; прежние черновики сохранены. Текст не отправляется на сервер.

## Исправление отправки из Outlook для Mac

Копирование и скачивание HTML создают таблицу фиксированной ширины 800 px. Каждая таблица, ячейка и картинка имеет явную ширину в HTML-атрибуте и inline CSS; картинки также имеют явную высоту. Текстовые ячейки имеют ширину 740 px и отдельные боковые ячейки по 30 px. Длинные слова получают невидимые возможности переноса; неразрывные пробелы из полей заменяются обычными.

В экспортируемом письме нет VML, CSS background-image, фоновых атрибутов и зависимости от процентной ширины. Пробка и стикеры собраны в обычные JPEG. Верхний отступ кнопки 60 px, сама кнопка 340×60 px, зазор после кнопки 60 px и нижний зазор под стикерами 30 px заданы отдельными фрагментами. Кнопка остаётся отдельной кликабельной картинкой с редактируемой ссылкой. Колокольчик — 20×20 px; линия создана границей таблицы. Текстовые блоки остаются обычным текстом.

Режим «Телефон» показывает вариант шириной 400 px, но копирование и скачивание всегда создают версию 800 px. На узком окне получателя может потребоваться горизонтальная прокрутка; это выбранный компромисс для отправки через настольный Outlook. Предпросмотр не является проверкой полученного письма.

## Отправка

1. Обновите редактор, заполните поля и ссылку.
2. Нажмите «Скопировать для Outlook» и вставьте в НОВОЕ письмо, не редактируйте старую вставку. При необходимости выберите «Сохранить исходное форматирование».
3. Отдельно добавьте тему и получателей. Отправьте тест и проверьте именно полученное письмо на Mac и Windows.

Если почтовый клиент изменяет письмо при отправке, для диагностики нужен исходник полученного письма (.eml), а не только предпросмотр в браузере. Реальная отправка и получение в Outlook в этом окружении не проверены.

## Файлы

Сайт не требует сборки. Для публикации нужны index.html и все семь board-*-v1.jpg в одной папке retro. Новые фрагменты загружаются с GitHub Pages; шапка, дата и колокольчик — с Sendsay. Не удаляйте опубликованные JPEG: письма с внешними картинками продолжают использовать их адреса. Надписи в изображениях не редактируются текстовыми полями.

Исходный адаптивный макет outlook-retro-800-background/email.html сохранён отдельно. Проверочный экспорт новой версии: outlook-retro-800-background/email-outlook.html.

Документация Microsoft об ограничениях рендеринга, ширине и фоновых картинках: https://learn.microsoft.com/en-us/troubleshoot/dynamics-365/customer-insights/journeys/email/email-troubleshoot-rendering
