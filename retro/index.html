02 / Ваше письмо400–800 px

Тема

Для отправки из Outlook письмо копируется с фиксированной шириной 800 px. Вставьте его в новое письмо через ⌘V или Ctrl+V. После обновления редактора создайте новое тестовое письмо.

Из редактора — в Outlook

  1. Измените текст в полях и вставьте ссылку для кнопки.
  2. Нажмите «Скопировать для Outlook».
  3. Откройте новое письмо и вставьте через ⌘V на Mac или Ctrl+V на Windows. При необходимости выберите «Сохранить исходное форматирование».
  4. Добавьте тему и получателей. Сначала отправьте тест себе.

Кнопка копирует письмо с оформлением. Скачанный HTML можно импортировать в сервис рассылок или HTML-редактор. Вставка кода в Outlook покажет код обычным текстом.

Черновик сохраняется только в этом браузере. Текст не отправляется на сервер. Картинки загружаются с Sendsay и GitHub Pages.

В режиме «Телефон» можно посмотреть макет на ширине 400 px. Для копирования и скачивания используется ширина 800 px с явными размерами всех таблиц и картинок. Кнопка остаётся отдельной кликабельной картинкой 340×60 px; колокольчик — 20×20 px. Фон со стикерами собран в обычные изображения: в отправляемом HTML нет фоновых слоёв и VML. После отправки проверьте полученное письмо.
