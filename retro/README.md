# Письмо · Ретро

Редактор приглашения: https://coopersino.github.io/mail-studio-light/retro/

Поля: заголовок, основной текст с несколькими абзацами, ссылка доски и текст в футере. Шапка, доска, дата, разделитель и подпись — внешние изображения на Sendsay. Ссылка применяется к изображению доски.

## Предпросмотр и отправка

Предпросмотр автоматически уменьшается по ширине узкого окна без горизонтальной прокрутки. Копирование и скачивание сохраняют исходную ширину письма 640 px. В HTML используются таблицы и inline CSS. Изображения имеют фиксированные размеры и alt; декоративный разделитель имеет пустой alt.

Нажмите «Скопировать для Outlook» и вставьте результат в новое письмо через Cmd+V или Ctrl+V. Если Outlook предлагает варианты вставки, выберите сохранение исходного форматирования. Тему и получателей добавьте в Outlook отдельно. Сначала отправьте тест и проверьте полученное письмо. Предпросмотр не заменяет тест реальной доставки.

«Скачать HTML» сохраняет готовое письмо с текущим текстом и ссылкой. Сам сервис не отправляет письма.

## Черновик

Текст сохраняется только в localStorage этого браузера. Изображения загружаются с Sendsay. Старые черновики с раздельными полями основного текста и приглашения добавить темы объединяются автоматически. Кнопка возврата исходного текста имеет отмену.

## Запуск и публикация

Приложение состоит из одного index.html, сборка и зависимости не нужны. Для локального запуска в его папке выполните python3 -m http.server 8788 --bind 127.0.0.1 и откройте http://127.0.0.1:8788/.

На GitHub Pages редактор размещён в retro/index.html репозитория mail-studio-light. Основной редактор в корне репозитория сохраняется. Встроенный шаблон письма не синхронизируется автоматически с последующими ручными изменениями отдельного HTML-файла. Пользовательские черновики в репозиторий не попадают.
