# Письмо · Ретро

Редактор приглашения на ретро с «Единым контентом». Адрес страницы: https://coopersino.github.io/mail-studio-light/retro/

В полях редактируются тема, заголовок, основной текст, приглашение добавить темы, текст о длительности встречи, подпись и ссылка кнопки. Изменения видны в предпросмотре. Переводы строк сохраняются; пустое поле убирает соответствующий текстовый блок. Текст вводится обычным текстом, без HTML.

Кнопка «Скопировать для Outlook» помещает готовое письмо с оформлением в буфер обмена. Вставьте его в новое письмо через Cmd+V или Ctrl+V. Тема переносится отдельно. «Скачать HTML» сохраняет чистый HTML письма с текущим текстом и ссылкой. Сначала отправьте тест себе: почтовый клиент может изменить оформление при вставке.

Ссылка кнопки должна начинаться с https:// или http://. Пустое поле и # оставляют заглушку. Некорректная ссылка блокирует экспорт и подсвечивается рядом с полем.

Черновик автоматически сохраняется в localStorage этого браузера, отдельно от основного mail-studio-light. Текст не отправляется на сервер. Очистка данных браузера удаляет черновик. Кнопка возврата исходного текста имеет отмену.

Ширина письма — от 400 до 800 px. Размер кнопки — 340×60 px, колокольчика — 20×20 px. Под post-it сохранён отступ 30 px. Внешние изображения берутся из папки outlook-template/img на сервере Sendsay. Для фонов классического Outlook сохранён VML. Предпросмотр не заменяет тест в реальном Outlook.

Текст на шапке, стикерах, кнопке и картинке с датой уже встроен в изображения. Поля редактора меняют только текстовые блоки HTML.

Приложение состоит из одного index.html, не требует зависимостей и сборки. Для GitHub Pages файл размещён в retro/index.html существующего репозитория mail-studio-light. Основная страница сервиса сохраняется.

В index.html встроена копия текущего макета outlook-retro-800-background/email.html. Дальнейшие ручные изменения исходного макета не переносятся в сервис автоматически. Пользовательские черновики в репозиторий не попадают.
