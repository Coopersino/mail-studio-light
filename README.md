# Письмо Light

Облегчённый редактор HTML-писем и рассылок `mail-studio-light`.

В интерфейсе убраны подпись автора, ссылка на репозиторий и вкладка просмотра HTML-кода. Доступна только ширина 600 px. Скачивание HTML и копирование с оформлением сохранены. Черновик Light хранится отдельно от полной версии.

Редактор работает в браузере без установки и сервера приложений. Текст, изображения по HTTPS, кнопка, подпись, цвет и шрифт настраиваются рядом с предпросмотром. Есть шаблоны поздравления, приглашения и чистого письма, просмотр на узкой ширине, копирование с оформлением для Outlook и экспорт HTML.

## Как пользоваться

1. Выберите шаблон и измените содержание.
2. Нажмите **«Скопировать для Outlook»**.
3. В новом письме вставьте содержимое через `⌘V` на Mac или `Ctrl+V` на Windows. Если клиент предлагает варианты вставки, выберите **«Сохранить исходное форматирование»**.
4. Тему и получателей добавьте отдельно. Сначала отправьте тест себе.

Оформление должно быть видно до отправки. Вставка исходного HTML-кода в Outlook покажет код обычным текстом. Для редакторов, умеющих импорт HTML, есть скачивание `email.html`.

Черновик автоматически сохраняется в `localStorage` этого браузера. Сервис не отправляет текст на сервер и не отправляет письма. Изображения загружаются с указанных пользователем внешних адресов. Очистка данных браузера удаляет черновик; для переноса результата сохраните HTML. Обратного импорта HTML в редактор в этой версии нет.

## Совместимость

Письма используют табличную разметку и inline CSS, содержат обычный текст и внешние изображения. Ширина — 600 px с сужением на мобильных экранах. Основной текст читается при отключённых изображениях.

Отображение и способ хранения картинок могут изменяться при вставке в почтовый клиент. Реальная отправка через Outlook и отображение во всех версиях почтовых клиентов не гарантируются предпросмотром; проверяйте тестовое письмо.

## Локальный запуск

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8767/`. Для копирования браузеру нужен HTTPS, localhost или подходящая поддержка резервного способа копирования.

## Публикация

Это статический сайт, сборка и зависимости не нужны. Для GitHub Pages выберите **Settings → Pages → Deploy from a branch → main → /(root)**. В репозиторий попадают только файлы приложения, без пользовательских черновиков.
